#   - 대문자로 시작(영어일 때), 마침표 없이, 간결하게
#   - type은 하나만 고른다:
#       feat     새 기능, 새 함수 · 클래스 · API 추가
#       fix      버그 수정, 에러 처리, 잘못된 로직 수정
#       docs     문서 · 주석만 변경
#       refactor 동작은 그대로 두고 구조 · 이름 변경
#       remove   파일 · 코드 제거
#       chore    빌드 설정, 패키지, 환경 설정 변경
#       test     테스트 추가 · 수정
#       enhance  기존 기능의 성능 개선, 최적화
